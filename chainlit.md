# Catence Console

Ask evidence-first questions about your local training and wellness data. The
Console uses the same Catence MCP tools available to your coding agent and
shows the tool calls that support each response.

Choose a named model profile in the settings, then try a recovery review,
training-load check, weekly summary, or a question about a recent activity.

Catence is not medical advice. Treat missing measurements as missing evidence,
not a conclusion about your health.
